# Security policy

## Supported version

The production `main` branch is the supported version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include credentials, personal data, waitlist submissions, or Telegram
configuration in a public issue.

Reports should include the affected route or component, reproduction steps,
impact, and any suggested mitigation. Operational questions that are not
security-sensitive may use a regular GitHub issue.
